# Blackjack on PC

After the credits reach “The End,” enter the original PC sequence with your current game bindings.

1. Right Trigger, Left Bumper, Right Trigger, Right Trigger.
2. Up, Cancel, Right, Confirm.
3. Down, Menu, Left Trigger, Right Bumper.
4. Right Trigger, Left Bumper, Special, Special.

The game chimes when it accepts the code. The mod then announces the currently bound Pause button or key. Press Pause to enter. On a controller, use the input that normally opens the pause screen.

Set the wager with the native increase and decrease controls or the shoulder buttons. The reader announces the displayed bankroll and settled wager. Confirm the deal, then use normal menu navigation to choose Stand, Hit, Double or Split as the game makes them available. Cancel uses the game’s normal exit.

The reader announces the cards drawn face up, identifies back-facing cards without identifying their ranks, and reads available totals and the visible win, loss or draw result. For a split, each hand has its own cards, totals and result. The controls and rules stay with the game. Live controller, keyboard and screen-reader testing remain open.
